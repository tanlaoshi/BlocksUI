# 00 · BlocksUI 概述

| 项 | 内容 |
| --- | --- |
| **产品名** | BlocksUI |
| **定位** | Ubuntu 桌面主机侧「拖控件」设计器；导出 `.uitxt` 给 Bingo 应用模板 |
| **仓库** | 独立 Git：`~/BlocksUI`（与 Blocks / HotSend 姊妹） |
| **规范正本** | Blocks `Bingo/App/UI/` |
| **非目标（首期）** | 板上跑设计器；嵌套容器；样式表；多文档；改 Blocks 开始菜单 |

## 一句话

学生在 PC 上摆 Button / Label / CheckBox / TextBox → 导出 `.uitxt` → `uitxt2h` → `MyAppUi.h` → 只填 `OnId*` → `exec MYAPP.ELF`。

## 分层

```
┌─────────────────────────────┐
│  BlocksUI Gui（GTK4）        │  三栏：控件板 / 画布 / 属性
├─────────────────────────────┤
│  BlocksUI Model（纯 C）      │  Document / Widget / Uitxt 导出；无 GTK
└─────────────────────────────┘
         │ .uitxt
         ▼
   Blocks Bingo Examples + uitxt2h → ELF
```

- 公开符号全称前缀 `BlocksUI…`；单文件 ≤300 行。  
- 设计画布逻辑 **1280×720**（显示可缩放）。
