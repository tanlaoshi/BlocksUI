# 04 · 多页分段 ID（策略 A）

正本：Blocks [`Bingo/App/UI/多页面分发.md`](../../Blocks/Bingo/App/UI/多页面分发.md) §3.1。  
BlocksUI **不**生成业务 `OnId*`；只提示区间、按页给 `id` 前缀。

## 区间

| 页面 | 逻辑号 | `id` 前缀 |
| --- | --- | --- |
| Home | 1000–1099 | `home_` |
| Settings | 1100–1199 | `settings_` |
| About | 1200–1299 | `about_` |
| Files | 1300–1399 | `files_` |
| Nav（全局导航） | 9000–9099 | `nav_` |

例：Home 下放置按钮 → `id=home_btn1`，右侧提示 `logic 1000`。  
`uitxt2h` 仍按字符串生成 `ID_HOME_BTN1`；板上路由用区间号是学生在分发层对齐的约定。

## 设计器边界

| 会做 | 不会做 |
| --- | --- |
| 页下拉 + 区间 / next logic 提示 | 多文档多 `.uitxt` 页文件 |
| 新控件 `id` 带页前缀 | 生成 `Dispatch` / 业务逻辑 |
| 选中项显示建议逻辑号 | 改物理槽 0..3 ABI |
