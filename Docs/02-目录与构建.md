# 02 · 目录与构建

## 目录

```
BlocksUI/
  Code/Model/     Document + Uitxt 导入/导出 + History（无 GTK）
  Code/Gui/       GTK4 窗体
  Tools/          uitxt2h.py、install-desktop.sh
  Assets/icons/   hicolor 多档 PNG
  Docs/
  Build/          meson 产物（可不入库）
```

## 依赖

- Meson ≥ 0.61、Ninja、pkg-config  
- GTK4 开发包：`libgtk-4-dev`（Debian/Ubuntu）

## 编译与运行

```bash
cd ~/BlocksUI
meson setup Build/meson
meson compile -C Build/meson
./Build/meson/Code/blocksui-gui
./Build/meson/Code/blocksui-import-smoke
```

## 桌面图标 / 菜单

```bash
chmod +x Tools/install-desktop.sh
./Tools/install-desktop.sh
```

对齐 HotSend：应用 ID `com.blocks.blocksui`；从菜单/桌面启动便于 Dock 认图标。

导出的 `.uitxt` 可拷到 Blocks `Bingo/App/Examples/UiDesigner/`，再 `python3 Tools/uitxt2h.py …` 生成头文件。
