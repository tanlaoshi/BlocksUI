# 02 · 目录与构建

## 目录

```
BlocksUI/
  Code/Model/     Document + UitxtExport（无 GTK）
  Code/Gui/       GTK4 窗体
  Tools/          uitxt2h.py
  Docs/
  Build/          meson 产物（可不入库）
  Assets/
```

## 依赖

- Meson ≥ 0.61、Ninja、pkg-config  
- GTK4 开发包：`libgtk-4-dev`（Debian/Ubuntu）

## 编译与运行

```bash
cd ~/BlocksUI
meson setup Build/meson
meson compile -C Build/meson
./Build/meson/Code/blocksui-gui
```

导出的 `.uitxt` 可拷到 Blocks `Bingo/App/Examples/UiDesigner/`，再 `python3 Tools/uitxt2h.py …`（本仓 `Tools/uitxt2h.py`）生成头文件。
